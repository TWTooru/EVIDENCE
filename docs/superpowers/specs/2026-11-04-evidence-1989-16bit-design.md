# EVIDENCE 1989: BLACK RAIN — 16-bit 設計文件

> TNDA Game Design · Cycle 02 ORIGINAL · 16-bit War 疊加擴增
> 繼承作品：《EVIDENCE 1976》

---

## 1. 核心願景與設計本質

### 1.1 一句話
> **深夜暴風雨中拋錨的旅行車。你只有 4 張底片和一台會引爆強光閃光的相機。
> 「它」只在你不看它的時候靠近。想把它拍清楚，你就得先把視線移開——但這一次，你把背後交給了整片黑暗的車廂。**

### 1.2 從 Cycle 1 到 Cycle 2 的蛻變
在 Cycle 1《EVIDENCE 1976》中，我們建立了核心博弈：**「想拍清楚，就得先移開視線；貪婪與恐懼是同一個動作」**。然而受限於 1970 年代街機技術，前作面臨「觀景窗像手電筒」、「玩家容易盲猜」與「空間感薄弱」的瓶頸。

在 Cycle 2 跨入 **16-bit War 時代（1989~1992 年代風貌，SFC / Mega Drive / PC Engine 世代）**：
1. **硬體能力釋放**：運用多圖層視差捲軸（Parallax Scrolling）、豐富且深沉的 16-bit 暗夜調色盤、以及雙耳立體聲空間聲相（Stereo Panning）。
2. **空間實體化**：不再只是螢幕上的黑白框，而是將玩家封閉在拋錨的旅行車駕駛座中。「移開視線」成為具體的生理行為——轉頭看右窗，左側與後方就成了致命盲區。
3. **消除盲猜**：透過老舊車載 AM 收音機的超自然雜訊（頻率干擾）與立體聲空間音效，讓玩家透過環境線索「可推理」生物方位，達成極致的心理恐怖與時機博弈。

## 2. 世界觀與情境設定

- **時代背景**：1989 年 11 月，美國奧勒岡州喀斯開山脈深處的泥濘林道。
- **主角身分**：一位任職於地方八卦獵奇週報《THE EYE》的獨立自由攝影調查員。
- **情境起點**：追查連環目擊報告時，老舊旅行車（Station Wagon）因電系故障拋錨在暴風雨深處，車輛無法發動。
- **威脅（「那個東西」）**：在狂風暴雨中遊蕩的高瘦陰影生物，雙眼散發冷冽猩紅微光。牠對直接視線極度敏感——被注視時靜止隱匿，一旦目標移開視線便疾步逼近，意圖撞破車窗。
- **防禦手段**：老舊相機的高壓閃光燈。強烈閃光能逼退生物並留下證據，但在雨夜車窗上會殘留 1 秒的白盲殘影，且高壓電容每次充能需要 2.5 秒。

## 3. 視角與 16-bit 畫面表現

### 3.1 視訊規格與解析度
- **邏輯內部解析度**：經典 16-bit **320 × 240** 像素，Canvas 自動等比整數倍放大（Pixel-perfect nearest-neighbor scaling）。
- **全景畫布寬度**：**640px**，玩家透過平滑轉頭（橫向平移相機）在車廂內環顧（平移範圍 0 ~ 320px，轉動耗時約 0.6 秒）。

### 3.2 視差圖層架構（4-Layer Parallax）
1. **遠景層（Far Sky）**：深紫黑色夜空、暴雨雲層，偶有全畫面閃電劃破天際，短暫暴露出遠方整片嶙峋樹海剪影。
2. **中景層（Forest & Mud）**：隨風雨劇烈搖晃的針葉林木、泥濘道路，生物在此層潛行、橫移、進逼，或隱藏於樹幹後露出猩紅眼眸。
3. **車窗玻璃層（Window Glass）**：
   - 傾斜而下的即時雨水粒子動畫。
   - 前擋風玻璃隨時間累積的模糊水膜（Water Film Blur）。
   - 雨刷刮過時產生的清晰扇形弧區。
   - 快門閃光引爆時，整面濕滑玻璃殘留的強烈白色反光。
4. **前景車廂層（Foreground Cockpit）**：
   - 駕駛座深色皮革方向盤、車門把手、車窗窗框。
   - 中央頂部懸掛的**車內後照鏡**（映出後座車窗與車後黑暗）。
   - 中控台**儀表板**（電瓶指針、大燈開關、雨刷旋鈕、發出微光的 AM 收音機調頻面板）。
   - 副駕駛座上的拍立得顯影相機與底片盒。

## 4. 車廂空間與操作配置

### 4.1 空間區域劃分
```
[ 0px ------------------ 200px ------------------ 440px ------------------ 640px ]
|   左側車窗區域         |   中央正前方視野       |   右側車窗區域         |
|   (駕駛座車門/後方盲區) | (擋風玻璃/後照鏡/儀表) | (副駕車窗/手套箱/底片)  |
```
- **左窗 (0 ~ 200px)**：觀察車身左側林道。
- **前擋與中央 (160 ~ 480px)**：觀察正前方、上望後照鏡、下探車載儀表。
- **右窗 (440 ~ 640px)**：觀察車身右側深林。

### 4.2 控制鍵位配置（零車輛操作，純視線與相機）

| 動作 | 鍵盤／滑鼠操作 | 設計意圖 |
|---|---|---|
| 左右轉頭 | `A` / `D` 或 `←` / `→` | 在左窗、前擋、右窗之間平滑轉頭；看一扇窗時另外兩扇窗即成為盲區 |
| 舉起相機 (Aim) | 按住 `Shift` / `J` 或 `右鍵` | 將單眼相機貼上臉龐構圖（**遮住肉眼打破對視，讓怪物趁機朝鏡頭逼近**） |
| 快門閃光 (Shoot) | `Space` / `K` 或 `左鍵` | 引爆高壓閃光燈拍下照片並逼退怪物（造成 1 秒玻璃反光白盲與 2.5 秒電容回充） |

## 5. 核心機制與系統規則（純粹 123 木頭人減法提純版）

### 5.1 絕對死寂定格與觀景窗遮眼誘敵（Sacred 123 Wooden Man Loop）
- **車子僅為純粹「視覺外框包裝」（零車輛打雜系統）**：
  - 拔除電瓶、雨刷、大燈、天窗與收音機儀表。熄火的車廂與 A 柱窗框只負責「限制玩家一次只能注視一扇車窗」，方位推理完全透過雙耳立體聲（泥水腳步聲、斷枝聲、刮擦玻璃聲）與後照鏡微弱紅眼反光呈現。
- **肉眼直視＝100% 絕對死寂不動（Absolute Statue Stillness）**：
  - 只要生物位於當前車窗注視錐內且玩家未舉起相機（`!cockpit.vfActive`），生物**完全靜止（不移動、不抖動、不發聲）**，徹底貫徹「盯著不動」的木頭人本能恐懼。
  - 生物僅透過三種定格姿態預告威脅：`WAIT`（歪頭觀望 `0.55x` 慢行）→ `COIL`（壓低蓄力 `1.65x` 暴衝）→ `LUNGE`（貼臉高舉雙爪 `dist <= 0.36`，進入 `dist <= 0.34` 時玻璃浮現吐息白霧）。
- **舉起相機＝遮住肉眼打破視線（Viewfinder Lure）**：
  - 因為遠距離盯著它雖然 100% 安全，卻拍不出 `EVIDENCE` 照片；玩家必須**主動按住 `Shift` 舉起相機遮住自己的肉眼**（畫面四周壓暗），中斷眼神接觸，讓生物在觀景窗內朝鏡頭狂奔逼近，並在貼近車窗的瞬間扣下快門！

### 5.4 相機抓拍與照片評等（Camera & Appraisal）
- **閃光效果**：
  - 若生物在當前車窗視野內，閃光逼退生物（距離重置至遠處 0.95）。
  - **代價 1：車窗反光致盲（Glare Blind）**：車窗玻璃反光致盲 **1.0 秒**，期間注視判定完全無效。
  - **代價 2：電容充電（Capacitor Charge）**：高壓電容需要 **2.5 秒** 蓄電，蓄電完成前無法再次閃光。
- **底片限制**：
  - 每晚配給 **4 張底片**。
- **照片評分公式**：
  - 照片得分 = $\text{Fill Ratio} \times 0.6 + \text{Center Accuracy} \times 0.4$。
  - **BLURRY（模糊）**：距離遠（`dist > 0.6`）或身體大半在窗外。
  - **SUSPICIOUS（可疑）**：中距離（`0.3 < dist <= 0.6`），拍到部分反光眼眸或軀幹。
  - **EVIDENCE（證據級）**：近距離（`dist <= 0.3`），生物撲在車窗上，軀幹與猩紅雙眼完整在觀景窗內。

## 6. 三夜進程關卡設計

每晚長度為 **90 秒**（遊戲內時鐘自 00:00 推進至 05:00）：

### 6.1 第一夜：試探之夜（Night 1: The Stalker）
- **天氣**：普通夜雨，電瓶全新（100% 電量，消耗標準）。
- **威脅配置**：單一生物實體，以標準速度（`approach = 0.05`）輪流從正前方、左窗、右窗發動試探。
- **目標**：熟悉轉頭平移操作、收音機聽聲辨位、前擋刮水與閃光快門節奏。

### 6.2 第二夜：暴雨與車頂之夜（Night 2: The Downpour & Roof Prowler）
- **天氣**：特大豪雨，雷聲陣陣。前擋雨水累積速度提高 80%，雨刷成為核心生存要素。
- **威脅配置**：生物移動速度提升 30%，並新增「攀爬車頂」行為。當車頂傳來巨響時，生物在 4 秒內若未被抬頭閃光驚退，將直接破開天窗。
- **目標**：在暴雨與電量消耗的雙重壓力下，成功抓拍一張證據照片並存活。

### 6.3 第三夜：絕境之夜（Night 3: Blackout & Double Shadows）
- **天氣**：寒冷凍雨，電系老化（初始電量僅 75%，耗電加劇 30%）。
- **威脅配置**：雙重威脅（兩隻生物，或主生物伴隨虛晃假影）。一側以聲響引誘玩家轉頭，另一側在盲區發動致命衝刺。
- **目標**：精打細算每一滴電與每一張底片，完成終極照片並迎接天亮逃生。

### 6.4 勝負條件
- **過關（Night Cleared）**：撐至 05:00 黎明，且當晚至少拍得 1 張「EVIDENCE」級照片。
- **遊戲失敗（Game Over）**：
  - **破窗死亡**：生物距離到達 0.0 且未被及時閃光驅退，撞碎車窗撲殺玩家。
  - **調查終止**：底片 4 張耗盡且無證據照片，或天亮時無證據照片。

## 7. 軟體架構與模組設計

遵循嚴格的高內聚、低耦合原則，全案切分為 4 個獨立模組：

```
[ evidence-16bit.html ] (進入點)
   ├── [ evidence-16bit-core.js ]   (純邏輯：狀態機、空間座標、AI、電瓶、水膜、評分)
   ├── [ evidence-16bit-render.js ] (Canvas 2D 視差渲染：天空、樹林、車窗、雨水、車廂內裝)
   └── [ evidence-16bit-audio.js ]  (Web Audio 立體聲合成器：雨聲、收音機雜訊、立體聲足音、快門)
```

### 7.1 `evidence-16bit-core.js`（純邏輯引擎）
- **環境獨立性**：零 DOM / 零 Canvas 依賴，可在 Node.js 與瀏覽器通用（CommonJS / Browser Global）。
- **主狀態機**：`TITLE` → `NIGHT_INTRO` → `PLAYING` → `FLASH_BLIND` → `NIGHT_SUMMARY` → `GAME_OVER` / `VICTORY`。
- **資料結構**：
  - `cockpit`: `{ panX, vfActive, battery, wipersOn, rainBlur, headlightsOn, radioPan, radioIntensity }`
  - `camera`: `{ filmLeft, chargeTimer, blindTimer, lastPhoto }`
  - `creatures`: `[ { id, dir: 'LEFT'|'FRONT'|'RIGHT'|'ROOF', dist: 1.0..0.0, state: 'STALKING'|'FROZEN'|'BREACHING' } ]`
  - `night`: `{ number, timeElapsed, duration: 90, evidenceCount }`
- **關鍵純函數**：
  - `update(dt, input)`: 推進物理與時間狀態。
  - `isCreatureGazed(c, panX, rainBlur)`: 計算注視凍結。
  - `takePhoto(state)`: 計算閃光判定、距離、構圖覆蓋率與相片評級。

### 7.2 `evidence-16bit-render.js`（16-bit 像素渲染器）
- 320×240 畫布，640px 視差層級繪製。
- 車廂內裝細節：方向盤陰影、會隨電量抖動的電瓶指針、按鈕機械下壓狀態、後照鏡動態影像。
- 暴雨與水膜特效：雨滴斜切下落、前擋水痕扭曲與雨刷掃過後的扇形清空遮罩。

### 7.3 `evidence-16bit-audio.js`（立體聲空間合成器）
- 使用 Web Audio API 原生節點合成，無外部依賴。
- `StereoPannerNode` 實現左右聲道即時運算。
- 收音機超自然雜訊生成器、高壓快門閃光衝擊波、車窗雨聲粉紅噪音濾波。

### 7.4 `tests/core-16bit.test.js`（自動化單元測試）
- 覆蓋核心邏輯驗證：
  1. 鏡頭轉向與注視凍結判定。
  2. 雨刷關閉時前擋水膜累積與注視失效邊界。
  3. 電瓶在各設備開啟時的消耗速率與斷電邊界。
  4. 快門閃光逼退生物、底片扣除與 EVIDENCE 評級計算。
  5. 三夜關卡時間流逝與過關/失敗狀態流轉。

## 8. 結論與後續執行步驟

本規格完整承接了《EVIDENCE 1976》的核心靈魂，並在 16-bit 世代硬體能力的想像下，透過「老舊旅行車空間」、「多層視差滾動」、「車載設備博弈」與「立體聲空間追蹤」實現了全面昇華。

依照 Superpowers 流程，本規格文件提交審閱後，下一步將啟動 **`writing-plans`** 撰寫詳細的實作計畫，進而落實可玩版本。
