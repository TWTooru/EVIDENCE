# EVIDENCE 1976 — 設計文件

> TNDA Game Design · Cycle 01 ORIGINAL · WP02 提案
> 備選名稱：*LOOK AWAY*、*LAST EXPOSURE*

## 一句話

> **深夜，森林邊緣。你只有 3 張底片和一台會閃光的相機。
> 「它」只在你不看它的時候靠近。天亮前，拍下一張能證明它存在的照片。**

---

## 1. 核心體驗

**想把它拍清楚，你就得先移開視線。**

「它」只在不被注視時靠近。要拍出好照片，就得讓它靠近；要讓它靠近，就得主動把視線移開，把背後交給黑暗。貪婪和恐懼是同一個動作。

情緒曲線：**等待 → 屏息 → 按下快門 → 閃光後的一秒靜默 → 它又開始移動。**

### 設計出發點

拍照的本質不是射擊或打靶，而是**注視**：那一刻只會出現一次，你必須等，但等得越久，就越可能錯過，甚至被發現。本作把「注視」直接做成機制，觀景窗既是武器，也是破綻。

---

## 2. 世界觀

- **時代**：1976 年，美國小報熱衷追查未知生物的年代。
- **地點**：深夜的森林邊緣，固定單一場景。
- **「它」**：沒有名字，不做任何解釋。比人還高的細長黑影，加上兩點紅色的眼睛。小報稱之為「那個東西」。
- **玩家**：獨自帶著相機守夜的人，目標是拍下「證據」。

---

## 3. 視角與畫面

- **第一人稱觀景窗視角**：整個 320×320 畫面就是玩家眼前的森林邊緣。
- **縱深**：「它」從遠處黑暗中出現，越靠近畫得越大（依距離縮放的偽 3D）。
- **觀景窗**：一個在畫面上移動的矩形框（暫定約 100×80 邏輯像素）。框內被照亮、看得清楚；框外是夜色，只看得到深藍輪廓。
- **核心視覺語言**：它在畫面上**越大，代表越危險，也代表照片越好**。

---

## 4. 操作

| 輸入 | 動作 | 設計重點 |
|---|---|---|
| 方向搖桿 | 移動觀景窗框 | 移動速度**固定且偏慢**。把視線移回去要花時間，這段時間就是風險 |
| 按鍵 | 快門加閃光 | 閃光需要充電（有充電音），不能連按 |

---

## 5. 規則

### 5.1 注視（凍結）
- 「它」的**紅眼睛位於觀景窗框內**時，它完全靜止。

### 5.2 靠近
- 眼睛不在框內時，它會：
  - 朝玩家靠近（距離減少、畫面上變大）；
  - 在樹與樹之間橫向移動，迫使玩家重新尋找它。

### 5.3 線索（框外追蹤）
- **紅眼閃光**：在框外時，眼睛每隔一段時間會閃一下紅光，讓玩家用眼角餘光追蹤。
- **心跳聲**：節奏隨它的距離加快。
- **樹枝斷裂聲**：它移動時偶爾發出。

### 5.4 拍照
- 按下按鍵 → 快門聲加全畫面閃光。
- **照片評分 = 它的大小（距離）× 完整度（身體是否完全在框內）**。
- 評級分成三級：

| 評級 | 條件（暫定） |
|---|---|
| 模糊 | 太遠，或大半身體在框外 |
| 可疑 | 中距離，或只拍到部分身體 |
| 證據 | 近距離，而且整個身體完整在框內 |

- 拍完後，畫面角落會**馬上**顯示這張照片的小縮圖和評級。

### 5.5 閃光的代價
- 「它」被逼退回遠方的黑暗中（距離重置）。
- 玩家**致盲約 1 秒**：畫面白色淡出，期間觀景窗無法凍結它。

### 5.6 一晚的結構
- 每晚 **3 張底片**、**約 60 秒**（到天亮為止）。
- 典型循環：放它靠近 → 拍照 → 被逼退 → 再放它靠近，每一次都更貪心一點。

### 5.7 勝負
- **過關**：天亮前拍到至少一張「證據級」照片 → 進入下一晚。
- **Game Over**：
  - 它碰到你（剪影填滿整個畫面，紅眼，尖叫）；或
  - 天亮了，或底片用完，卻沒有任何證據級照片。

---

## 6. 遊戲流程（狀態）

```
待機畫面 ATTRACT
  → 第 N 晚 PLAY
  → 洗照片 DEVELOP（展示本晚最好的一張與評級）
  → 下一晚 / GAME OVER
  → 高分榜
  → 待機畫面
```

### 30 秒教學
- 待機畫面直接示範「框住就停、移開就來」。
- 只配一行字：**"IT ONLY MOVES WHEN YOU LOOK AWAY."**
- 第 1 晚開頭幾秒，它在框內清楚可見，讓玩家先體驗一次凍結的效果。

---

## 7. 關卡升級

| 夜晚 | 變化 | 玩家要學會的事 |
|---|---|---|
| 1 | 一隻，速度慢 | 看它就不動，移開它就來 |
| 2 | 變快，會在樹後移動 | 不能只靠眼角餘光 |
| 3 | 兩隻 | 必須取捨要盯哪一隻 |
| 4 以後 | 兩隻變得更快，時限更短 | 拚分數、拚極限 |

### 計分
- 分數 = 每張照片的評分總和 + 過關的晚數加成。
- 高分榜輸入 3 個英文字母縮寫。

---

## 8. 規格對照

| 限制 | 本作的對應方式 |
|---|---|
| 單畫面、不捲動 | 固定的森林邊緣場景 |
| 320 × 320 | 靠剪影縮放做出縱深 |
| ≤ 4 色 | 黑（夜色）、深藍（樹與剪影）、白（框內照明與閃光）、紅（眼睛／危險） |
| ≤ 3–5 種電子聲音 | 心跳、樹枝斷裂聲、閃光充電聲、快門聲、尖叫 |
| ≤ 8–10 個活動物件 | 觀景窗、它（最多 2 隻）、樹（3–4 棵）、閃光、照片縮圖 |
| Play → Win/Lose → Restart | 每晚過關或 Game Over，經過高分榜後回到待機畫面 |
| 方向搖桿 + 一顆按鈕 | 搖桿移動觀景窗；按鈕是快門加閃光 |

---

## 9. 街機的兩道門

- **30 秒內看懂**：規則只有一句「它只在你不看它的時候靠近」，靠待機畫面示範就能學會，不需要文字說明。
- **Game Over 後還想再投幣**：
  - 第三張底片通常是最貪心的一張，大多數死亡都發生在這裡；
  - 「洗照片」時看到自己只差一點點就是證據級，悔恨感最強。

---

## 10. WP02 比較欄位

| 項目 | 評估 |
|---|---|
| 理解門檻 | 低。一句話規則，示範就懂 |
| 重玩動機 | 越來越貪的第三張底片，加上洗照片時的「差一點」 |
| 製作可行性 | 高。核心只有一個移動的框、1–2 個縮放的剪影，加上距離計算 |

---

## 11. 下一步要驗證（NEXT TEST）

1. **速度平衡**：觀景窗的移動速度和它的靠近速度，比例多少才會「緊張但公平」？
2. **框外追蹤**：玩家能不能只靠紅眼閃光和心跳聲追蹤它，而不覺得自己死得莫名其妙？
3. **評級的可讀性**：玩家拍完能不能馬上看懂自己差在哪裡（太遠，還是沒框完整）？

**建議的紙上原型**：一張畫有森林的紙代表畫面，一張挖空的卡片代表觀景窗，一枚棋子代表「它」。由一人扮演「它」，只在觀景窗沒蓋住時往前移一格；另一人操作觀景窗並決定何時「拍照」，用來快速測試第 1、2 點。
