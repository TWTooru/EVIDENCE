## 1. 減法提純（Subtraction Audit）：砍掉所有稀釋恐懼的干擾項

為了讓玩家的每一秒注意力都集中在**「黑暗中死盯著那個不動的人影」**，我們將原版所有《FNaF》式的巡邏打雜與 UI 提示全數拔除：

| 被砍除的「加法／干擾」項目 | 為什麼必須砍掉？ | 提純後的替代體驗 |
|---|---|---|
| **`[1]` 雨刷、`[2]` 大燈、`[W]` 天窗、`BATT%` 電瓶、AM 收音機波形表** | 讓玩家忙著算電量、按開關打雜，大腦進入「資源管理模式」而非「本能恐懼模式」。 | **車子退回純粹的「視覺外框包裝」（零車輛操作）**：熄火的方向盤、A 柱窗框與雨夜玻璃只負責限制視野（一次只能看一扇窗），定位完全仰賴雙耳立體聲（泥水腳步聲、斷枝聲、刮玻璃聲）。 |
| **`GAZE TENSION` UI 進度條與當面違規移動** | 當玩家睜眼盯著怪物時怪物還會當面移動，直接破壞了「盯著不動」的木頭人神聖鐵律；畫進度條更是 UI 加法。 | **支柱二改為「生理強制眨眼（Involuntary Blink）」**：睜眼時怪物 **100% 絕對死寂不動**；但死盯滿 `4.0` 秒上下眼皮會逐漸酸澀壓黑並**強制眨眼黑屏 `0.22` 秒**，怪物就在你閉眼的那 0.22 秒瞬間跳剪突進！ |
| **`EVIDENCE RANGE!` 綠字與 QTE 提示框** | 系統幫玩家判斷距離，把未知的壓迫感變成「等綠字亮按空白鍵」的反應遊戲。 | **純環境視覺／聽覺線索（Diegetic Tells）**：沒有任何文字提示。玩家必須靠怪物的定格姿態（高舉雙爪的 `LUNGE` 態）、貼在玻璃上的慘白吐息霧氣、以及指甲刮擦車窗聲，自己賭「夠近了沒」。 |

## 2. 純粹「123 木頭人 × 拍照」的三大支柱

全作只剩兩個動作維度：**左右轉頭（`A / D`）** 與 **舉起相機／按下快門（`SHIFT` + `SPACE`）**。

### ① 絕對死寂與跳剪驚悚（Absolute Statue Stillness & Jump-Cut Horror）
- **肉眼直視＝絕對靜止**：當怪物位於當前車窗視野內且玩家未舉起相機（`!vfActive`）時，怪物進入 `FROZEN` 狀態——不移動、不抖動、不發聲。
- **餘光黑幕與三階段定格姿態（`WAIT` → `COIL` → `LUNGE`）**：
  - 視野外不顯示平滑滑動的身體，只偶爾閃現紅眼微光。
  - 每次視線中斷再看回來，怪物都會像恐怖片跳剪（Jump-cut）一樣瞬間換成更壓迫的定格姿態：
    1. **`WAIT`（歪頭直立觀望，`0.55x` 欺敵慢行）**：遠處樹影間歪頭死盯著你，初移開視線時故意走得很慢，誘使你掉以輕心。
    2. **`COIL`（壓低前傾蓄力，`1.65x` 暴衝）**：重心壓低、雙臂如螳螂張開——警告你下一次閉眼或轉頭時，它將大跨步撲向車窗。
    3. **`LUNGE`（貼窗高舉雙爪，`dist <= 0.36`）**：龐大黑影塞滿車窗、雙爪高舉過頭；當跨入 `dist <= 0.34` 的鐵證距離時，玻璃上會浮現冰冷的慘白吐息霧氣。

### ② 支柱二：凝視精神壓迫與「三次眨眼」致死跳剪（Uncanny Gaze Dread & 3-Blink Lethal Escalation — 零 UI 條）
- **完全守住「睜眼絕對不動」鐵律**：只要你的眼睛是睜開的，怪物的軀幹完全死寂不動。
- **為什麼「持續盯著」會越來越毛骨悚然？**
  1. **連續耳鳴與超低頻壓迫音（`updateStareDread`）**：對視瞬間開始，胸腔超低頻共鳴（`46Hz`）、不協和下滑音與高頻腦鳴耳鳴（`3120Hz+`）持續增強，移開視線才瞬間消失。
  2. **幽閉隧道視野與浮現的慘白詭臉（`drawCreature16Bit`）**：死盯越久，怪物四周的森林與車廂逐漸被黑暗隧道吞沒；同時黑影臉上慢慢浮現**凹陷慘白眼白、針孔紅瞳與縱向裂嘴慘白牙縫**，並在眨眼前一瞬間出現 `0.06` 秒的**潛意識歪頭折頸幻覺**。
  3. **三次眨眼致死跳剪（`Far → Mid → Glass Slam → Shatter`）**：不再是緩慢移動 10%，而是：
     - **第 1 次撐不住眨眼（約 2.6 秒）**：瞬間跨越半座森林跳剪至中距離蓄力態（`COIL`）。
     - **第 2 次撐不住眨眼（約 2.1 秒）**：**`WINDOW_SLAM` 撞窗驚嚇！** 全車劇烈震動，睜眼時**整張慘白裂嘴臉與兩隻蒼白四指手掌直接死死貼在你的玻璃上**！
     - **第 3 次眨眼（約 1.7 秒）**：若貼窗狀態下再眨一次眼，**車窗當場爆裂死亡（`BREACH`）**！

### ③ 支柱三：舉起相機＝遮住肉眼（Viewfinder Covers Naked Eyes）
- 為什麼「拍照」不是外掛加法，而是 123 木頭人恐懼的放大器？
  - 當你按住 **`[SHIFT]`** 把老式單眼相機貼上臉龐構圖時，沉重的機身遮住了你的肉眼（畫面四周壓暗為全黑遮罩，僅留中央 `120×96` 光學觀景窗與右上角一顆閃光電容指示燈）。
  - **因為相機擋住了你的臉，怪物看不見你的眼睛（眼神接觸中斷，`isCreatureGazed === false`）**！
  - 於是就在你舉起相機想拍它的那一刻，耳邊立刻響起急促逼近的泥水腳步聲——**它在觀景窗裡朝你的鏡頭撲過來了！**
  - 你可以隨時放開 `[SHIFT]` 放下相機露出肉眼把牠重新釘死在窗前，在「想讓它再近一點拍清楚」與「再近一步玻璃就要碎了」之間進行最純粹的膽量博弈。

### ③ 三夜純空間遞進（零新系統、純視線盲區升級）
- **Night 1（單一獵食者）**：1 隻怪物在左、前、右三扇窗外徘徊，建立「聽聲轉頭釘死 → 舉相機遮眼誘敵 → 貼臉閃光抓拍」的核心節奏。
- **Night 2（高速側翼包抄）**：暴雨加劇，怪物在盲區換窗與蓄力暴衝的速度提升（`1.25x`）。
- **Night 3（雙重黑影，只有一雙眼睛）**：**2 隻真實的木頭人同時存在於不同車窗外**。因為 A 柱窗框限制你一次只能看一扇窗（[`isCreatureGazed`](file:///C:/Users/user/Desktop/work/prototype/evidence-16bit-core.js#L152-L156) 確保沒有任何角度能同時釘死兩扇窗），當你盯著左窗或舉相機誘拍左窗時，右窗外的腳步聲正在一步步逼近——將 123 木頭人的視線分配恐懼推到極致。
