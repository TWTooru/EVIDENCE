CYCLE 01 ORIGINAL · 1976 ARCADE GAME JAM

EVIDENCE 1976 想把它拍清楚，你就得先移開視線。

深夜，森林邊緣。你只有 3 張底片和一台會閃光的相機。
「它」只在你不看它的時候靠近。天亮前，拍下一張能證明它存在的照片。

01 / CORE EXPERIENCE · 設計出發點

拍照不是射擊。
拍照是「等待與注視」。

多數遊戲把相機當成「換了皮的步槍」——看到目標、瞄準、扣板機。 但我們回到拍照最原始的心理張力：「那一刻只會出現一次。你必須等它夠近，但等得越久，你就越危險。」

THE CORE PARADOX / 核心拉扯

要拍出好照片，必須讓它靠近；
要讓它靠近，你必須主動把視線移開，把背後交給黑暗。

PHASE 01 注視凍結 框住紅眼，它完全不敢動，但照片太小（TOO FAR）
→
PHASE 02 主動移開視線 放它在黑暗中逼近，只靠紅眼閃光與心跳聲盲猜距離
→
PHASE 03 拉回觀景窗構圖 框移動偏慢，在最後關頭把全身塞進框內
→
PHASE 04 閃光快門！ 拍下證據或致盲 1 秒，被逼退後再來一輪
02 / MECHANIC LOOP · 核心互動

觀景窗既是你的武器，
也是你的破綻。

在第一人稱森林邊緣場景中，「它」在畫面上越大代表越危險，也同時代表照片分數越高。畫面本身就把風險與報酬講清楚了。

INPUT 01 · 方向搖桿

移動觀景窗（注視）

觀景窗的速度固定且偏慢（120 px/s）。把視線移開很容易，但要把視線移回來找它需要時間——這段時間差就是玩家心跳加速的來源。

  • 框內：白底照明，看清「它」與松樹前後關係
  • 框外：全黑夜色，每 1.5 秒閃一次紅眼反光
INPUT 02 · 單一按鍵

快門 ＋ 閃光燈

每晚只有 3 張底片。按下快門會瞬間照亮全場、將它往後逼退一段距離（+0.35），但你也會短暫致盲 1 秒且閃光燈需充電 2 秒。

  • BLURRY：距離太遠，尺寸不足
  • SUSPICIOUS：夠近但身體切出框外
  • EVIDENCE：佔框高 ≥85% 且全身 ≥95% 在框內
ESCALATION · 關卡推進

每過一晚，黑夜更殘酷

從第一晚的單純貪婪博弈，過渡到雙重威脅的顧此失彼：

  • Night 1：1 隻，速度慢，30 秒內學會核心規則
  • Night 2：移動變快，穿梭在松樹後方遮蔽
  • Night 3：2 隻同時出現，觀景窗一次只能定住一隻
  • Night 4+：速度再提升、天亮時限縮短
03 / THE TWO GATES · 街機的兩道門

30 秒內知道怎麼玩。
Game Over 後還想再投幣。

GATE 01 · 30 秒內上手

不靠說明書的直覺設計

  • 待機畫面一句話：直接展示紅眼閃爍與唯一規則 "IT ONLY MOVES WHEN YOU LOOK AWAY."
  • 開場即體驗「凍結」：第 1 晚開始時，觀景窗預設正對著第一隻「它」。玩家第一秒就看到「框住它就不動」，一移開搖桿就聽見樹枝斷裂與心跳加速。
  • 觀景窗即時取景提示：框底部直接告訴玩家 TOO FAR (XX%)、FIT FULL BODY 或紅框 EVIDENCE READY!，零學習門檻。
GATE 02 · 再投幣的重玩動機

死在「自己的貪心」與「只差一點」

  • 第 3 張底片的極限貪婪：前兩張拍出「可疑（SUSPICIOUS）」後，最後一張底片玩家一定會想放它貼到臉前再拍——大多數被抓（Jump Scare）都發生在這最貪的一秒。
  • 洗照片畫面的悔恨感：結算與 Game Over 會直接把這晚拍到最好的一張照片洗出來釘在畫面上。「只差把框再往下移一點就是 EVIDENCE 了！」讓人立刻想再按一次開始。
04 / 1976 SPEC CONSTRAINTS · 硬體限制轉化

把 1976 年的硬體限制，
變成恐懼氛圍的武器。

低解析度與少色彩若拿來畫寫實場景會顯得簡陋，但拿來表現「漆黑森林裡的相機觀景窗與紅眼剪影」，反而比高畫質更具壓迫感。

05 / BUILD → TEST → REFINE · 測試發現與迭代證明

我們測試到了什麼問題？
留下什麼、改變什麼？

在初版原型完成後，我們馬上遇到了「一直拍到 OUT OF FILM（底片用完卻拿不到證據）」與「場景直線不像樹」兩個核心問題。透過拆解原因，我們做了三項關鍵迭代：

ITERATION 01 · 取景回饋與準星陷阱

為什麼玩家一直 OUT OF FILM？

測試發現：紅眼位於頭頂（12% 高度處），當玩家直覺把「十字準星」對準紅眼時，「它」的下半身會有約 30px 露在觀景窗底邊外，導致完整度永遠卡在 70%（未達 95% 門檻）。而且拍之前完全不知道現在按快門會不會過。

BEFORE（初版問題） 觀景窗沒有任何距離或構圖提示；藍色準星容易融入背景。玩家看到它就盲按快門，連拍 3 張都是 BLURRY 或 SUSPICIOUS。
AFTER（決定留下的門檻 ＋ 新增回饋） 保留嚴格的 85% 大小 × 95% 完整度門檻，但將準星改為醒目琥珀黃，並在觀景窗下方新增即時狀態：TOO FAR (XX%) → FIT FULL BODY → 紅框 EVIDENCE READY!。
ITERATION 02 · 閃光分段逼退與關卡節奏

拍完一張要重等 10.5 秒太拖沓

初版每按一次快門，不論「它」原本多近，都會被直接重置回最遠處（dist = 0.95）。以初速計算，玩家必須移開視線乾等 10.5 秒才能再拍下一張，節奏過於斷裂。

BEFORE（初版問題） 閃光一律重置回 dist = 0.95；且各晚節奏差異只靠單一乘數。
AFTER（分段逼退 ＋ 逐晚加速） 閃光改為往後退一段距離（+0.35）而非退回最遠處；第 1 晚維持平緩教學步調，第 2 晚起逐步加快逼近速度、縮短逼退距離與紅眼閃光間隔。
ITERATION 03 · 場景視覺與前後景深度遮蔽

從「四條藍色直線」到「可躲藏的針葉林」

初版為了極簡，用四條從頂到底的藍色垂直長條代表樹木，視覺上像鐵欄杆而非森林，也無法呈現「它在樹後穿梭」的空間深度。

BEFORE（初版問題） 4 條貫穿全畫面的 fillRect 垂直藍線，沒有樹冠與地平線樹林，深度固定。
AFTER（五層階梯松樹 ＋ 真實深度排序） 重繪地平線遠方樹林剪影＋ 4 棵具樹幹、樹根與 5 層階梯針葉冠的松樹，並依 dist 動態排序繪圖順序，讓「它」在遠處會真正躲在樹後、靠近時才走出樹前。
